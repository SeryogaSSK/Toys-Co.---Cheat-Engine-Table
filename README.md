## Features

### 🎮 Gameplay
- **Coins** – Modify your available coins.
- **Capacity Multiplier** – Adjust the capacity multiplier.
- **Power Up Remaining** – Modify the remaining power-up duration or amount.
- **No Skill Cooldown** – Remove skill cooldown restrictions.
- **SkillPoint No Decay** – Prevent skill points from decreasing over time.

## Requirements
- Toys Co.
- Cheat Engine

## Installation
1. Download the `.CT` file from the repository.
2. Launch **Toys Co.**.
3. Open the `.CT` file with Cheat Engine.
4. Attach Cheat Engine to the game's process.
5. Enable the desired options and modify the available values.
